## О проекте

Учебный проект — адаптивный лендинг магазина украшений Distortion. Сайт выполнен в чёрно-белых тонах с элементами готической эстетики. На фоне медленно падают серебристые звёзды.

Цель проекта — представить ассортимент магазина и реализовать основные интерактивные элементы средствами HTML, CSS и JavaScript.

 Используемые технологии

- HTML5 — семантическая разметка страницы.
- CSS3 — оформление, анимация и адаптивная верстка.
- CSS Grid — сетки каталога, галереи и основных секций.
- Flexbox — навигация, кнопки и расположение элементов.
- JavaScript — интерактивность без фреймворков и библиотек.
- PT Mono — основной шрифт сайта.

 Структура сайта

1. Шапка с названием магазина и навигацией.
2. Главная секция с заголовком и кнопкой перехода к каталогу.
3. Каталог из 18 изображений с фильтрами по категориям.
4. Раздел о магазине.
5. Галерея украшений.
6. Контактный раздел с формой обратной связи.
7. Подвал с копирайтом и местами для контактной информации.

 Реализованные функции

- Плавная прокрутка по якорным ссылкам.
- Мобильное раскрывающееся меню.
- Фильтрация товаров: кольца, браслеты, звенья, подвески и цепочки, серьги.
- Модальное окно с фотографией и описанием выбранного товара.
- Автоматическое заполнение сообщения при выборе украшения.
- Проверка имени, email, сообщения и согласия на обработку данных.
- Скачивание текста обращения после успешной проверки формы.
- Анимация падающих звёзд.
- Отключение анимации при включённой системной настройке уменьшения движения.

 Файлы проекта

- `index.html` — структура и содержание страницы.
- `style.css` — стили, адаптивная верстка и анимация.
- `script.js` — каталог и интерактивные функции.
- `products.json` — данные о товарах.
- `README.txt` — описание проекта и инструкция по запуску.
